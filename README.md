# 🔢 Digit Recognition Using CNN (MNIST)

[![Great Learning Certificate](https://img.shields.io/badge/Great%20Learning-Project%20Certified-blue?style=for-the-badge&logo=google-scholar)](https://www.mygreatlearning.com/project-certificate/PC-C39938B0B59FA4C4)

This project implements a **Convolutional Neural Network (CNN)** to recognize
handwritten digits (0–9) using the **MNIST dataset**.

---

## 📌 Project Overview

Handwritten digit recognition is a fundamental problem in computer vision with
applications such as postal sorting, bank cheque processing, and OCR systems.

In this project, a CNN model is trained using TensorFlow to classify digits from
grayscale images.

---

## 🎯 Objectives

- Load and preprocess the MNIST dataset
- Normalize and reshape image data
- Build a CNN for feature extraction
- Train and evaluate the model on test data

---

## 🧵 Dataset Description

- **Dataset:** MNIST (built into TensorFlow)
- **Training Images:** 60,000
- **Test Images:** 10,000
- **Image Size:** 28 × 28
- **Classes:** Digits 0–9

---

## 🧠 Model Architecture

- Convolutional Layers (feature extraction)
- Max Pooling Layers
- Fully Connected (Dense) Layers
- Softmax Output Layer

**Loss Function:** Sparse Categorical Crossentropy  
**Optimizer:** Adam  

---
